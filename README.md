# POD原稿エディタ

電子用原稿（.docx）＋赤入れPDFから、POD（プリントオンデマンド）用の組版済み .docx を作るブラウザエディタ。
サーバー不要・ファイルはブラウザ内だけで処理（外部送信なし）。

## Web版

https://claude.ai/artifact/DKpNRb2963afzxqchqQ6bB （claude.ai上の非公開ページ。共有は画面右上のShareから）

公開用ファイルは `index.html` から `<html>/<head>/<body>` を外したもの（claude.ai側で付与されるため）＋ `css/`・`js/` をそのまま載せる。

## 入力

- 原稿：Word（.docx）またはテキスト（.txt、UTF-8／Shift_JIS）
- 赤入れ：PDF またはスキャン画像（.jpg／.png）、複数可

## ローカル起動

```bash
cd apps/pod-editor && python3 -m http.server 8000
```
→ http://localhost:8000 を開く（`index.html` を直接開いても動作します）。

## 作業の流れ

1. **原稿を読込**：.docx をドロップ。変更履歴は「すべて承諾」した状態で取り込み、画像も保持
2. **自動整形**：ルールを選んで適用（件数プレビューあり／⌘Zで戻せる）
   - 空段落削除・【第N章】マーカー削除・手動改ページ削除
   - 章タイトル（見出し1／第N章）→ 章扉＋柱、直後の「～…」→ 章副題
   - 節見出し（見出し2／「1－1　…」）、直後の「──…」→ リード「─ … ─」
   - 小見出し（◇／箇条書きスタイル）→「◇　」に統一
   - 画像＋「図1－1　…」→ 図版キャプション（「図1-1」表記）
   - 空白正規化（全角重複・和文間の半角空白）
   - 任意：強調ボックス候補、「――」→「……」
3. **赤入れPDF**：右パネルに表示。頁クリックで拡大＆頁番号入力。チェックリストで段落に紐付けて対応状況を管理
4. **編集**：本文を直接編集。Enter＝分割、先頭でBackspace＝結合、Alt+0〜6＝種類変更、ガターのラベル＝メニュー（Shift+クリックで範囲選択）
   - 「表に変換」：会社概要のような「項目　内容」の行を2列の表に（赤入れ「改行して揃えて」対応）
   - 「変更」タブ：読込時の原稿からの差分を一覧
5. **DOCX書き出し**：A5／游明朝10.5pt／見出し游ゴシック／ワインレッド。章ごとにセクション、柱（奇数頁右・偶数頁左）、ノンブル、目次（TOCフィールド）
   - Wordで開くと「フィールドを更新しますか」と聞かれる → 「はい」で目次のページ番号が入る

## マイページ（過去の作業一覧）

トップページはマイページ。このブラウザでアップロードした作業を、更新が新しい順に一覧表示する。

- クリックで続きから編集。ヘッダーの「POD原稿エディタ」または「マイページ」で一覧に戻る
- 新しい原稿をアップロードすると、作業が一覧に追加される（これまでの作業は上書きされない）
- 「削除」で作業データと赤入れを削除（確認あり・元に戻せない）
- 「開く」で読み込んだ .json も、新しい作業として一覧に追加する

作業内容はブラウザ（IndexedDB）に自動保存。データは利用者のブラウザごとに分かれ、他の利用者には見えない。
別のPC・ブラウザに引き継ぐときは「保存」で .json に書き出し、移行先で「開く」から読み込む。

IndexedDB のキー：`index`＝一覧（メタ情報）、`proj:<id>`＝作業データ、`red:<id>`＝赤入れ。
旧版の単一保存（`project`／`red`）は初回起動時に一覧へ移行する（旧キーは残す）。

## ファイル構成

- `js/docx-import.js` … .docx 解析
- `js/rules.js` … 自動整形ルール（POD最終版との差分から規則化）
- `js/docx-export.js` … POD用 .docx 生成
- `js/app.js` … エディタUI
